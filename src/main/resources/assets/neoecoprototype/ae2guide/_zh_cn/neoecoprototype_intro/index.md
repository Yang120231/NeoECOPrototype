# Neo ECO Prototype

Neo ECO Prototype 把 Neo ECO AE Extension 的后期内容带到 **L1 前期**。三大系统（存储 / 计算 / 合成）的耗电是 eco L4 同级的 **1/8**。

| 想做什么 | 看哪一页 |
|----------|----------|
| 建一套前期就能用的存储网络 | [L1 存储系统](storage_system.md) |
| 用样板自动化处理器 | [L1 处理器装配室](processor_assembler.md) |
| 大宗囤少数几种资源 | [小宗存储矩阵](small_bulk_matrices.md) |
| 把 FE 留在网格里 | [FE存储矩阵](flux_storage.md)（需要 AppliedFlux） |
| 把一整块电量存进网格 | [盈能能源元件](energized_energy_cells.md) |
| 不建凝聚器也拿到奇点 | [L1 奇点元件](singularity_cell.md) |
| 提升合成吞吐 | [L1 计算系统](computation_system.md) 与 [L1 合成系统](crafting_system.md) |
| 子网供电、大批量标记 | [L1 供能接口](powered_interface.md) 与 [盈能超导接口](superconductive_interface.md) |
| 用脚本注册矩阵与配方 | [KubeJS 支持](kubejs.md) |

两台接口不叠加：AE2 每个网格只保留输出功率最高的那台被动发电源。

三合一联合体仍在早期开发，未收进本指南。
